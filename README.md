# Consulta Acciones

Aplicación móvil en Streamlit para consultar los descuentos comerciales vigentes de cada cliente por código o nombre de fantasía.

Muestra el porcentaje máximo, la cantidad mínima de bultos y las acciones y grupos que componen cada beneficio.

## Ejecutar localmente

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## Fuente

El snapshot incluido fue auditado contra las acciones vigentes y programadas de Chess ERP para octubre de 2026.
